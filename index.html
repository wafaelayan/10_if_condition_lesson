استرجاع الخبرات السابقة

مقدمة: الشروط في لغة بايثون وبنية elif 💡

تُستخدم التعليمات الشرطية (if - elif - else) لاتخاذ القرارات وتنفيذ تعليمات معينة فقط عند تحقق شروط محددة.

1

معاملات المقارنة (Comparison Operators)

تُقارن بين قيمتين وتعطي نتيجة منطقية إما True (صحيح) أو False (خطأ):

== يساوي تماماً
!= لا يساوي
> أكبر من
< أصغر من
>= أكبر أو يساوي
<= أصغر أو يساوي
score = 90 ➔ (score >= 90) يُرجع True
2

التعليمة الشرطية elif (اختصار else if)

تُستخدم لإضافة شروط بديلة متعددة ومتسلسلة في حال عدم تحقق الشرط الأول (مثل فحص تقديرات درجات الطالبات):

# مثال تقديرات الدرجات:
if student_score >= 90:
print('Excellent grade !')
elif student_score >= 70:
print('Good grade !')
elif student_score >= 50:
print('Acceptable grade !')
else:
print('You have failed !')
📌 يتم فحص شروط elif بالتسلسل ويتوقف الفحص فور تحقق أول شرط صحيح.

الشرط المتداخل (Nested if Statement) 🔐

تعليمة شرطية تحتوي على تعليمة شرطية أخرى داخلها، وتُستخدم لفحص أكثر من شرط داخل البرنامج قبل اتخاذ القرار النهائي.

💻 الكود البرمجي (Python Code):

كل تعليمة بسطر مستقل
# مثال 6: التحقق من اسم المستخدم ثم كلمة المرور:
user_name = input('Enter user name: ')
user_password = input('Enter password: ')
if user_name == 'admin':
if user_password == '123@q8':
print('Login successful. Welcome admin!')
else:
print('Incorrect password.')
else:
print('User name not found.')
📋

الخوارزمية (Algorithm):

خطوات الحل المنطقية المتسلسلة والمطابقة تماماً لبنية الكود البرمجي:

  1. 1. البداية (Start).
  2. 2. استقبال اسم المستخدم user_name من المستخدم.
  3. 3. استقبال كلمة المرور user_password من المستخدم.
  4. 4. اختبار الشرط الخارجي: هل user_name == 'admin'؟
  5. • إذا نعم (True): اختبار الشرط المتداخل الداخلي: هل user_password == '123@q8'؟
    - إذا نعم: طباعة 'Login successful. Welcome admin!'
    - إذا لا: طباعة 'Incorrect password.'
  6. 5. إذا لم يتحقق الشرط الخارجي (False): طباعة 'User name not found.'
  7. 6. النهاية (End).

نشاط: محطة الأمان والشرط المتداخل 🔐

تتبعي الكود البرمجي التالي وتوقعي المخرجات الصحيحة بناءً على قيم المدخلات المعطاة:

🎯 التحدي الصفي للـ Nested if
# تتبعي تنفيذ الكود البرمجي التالي:
role = 'student'
device_pin = 2026
if role == 'student':
if device_pin == 2026:
print('Lab Access Granted!')
else:
print('Wrong PIN code.')
else:
print('Unknown Role.')
الحالة الأولى:
إذا كانت المدخلات:
role='student', pin=2026

ما الرسالة المطبوعة في الشاشة؟

الحالة الثانية:
إذا كانت المدخلات:
role='student', pin=9999

ما الرسالة المطبوعة في الشاشة؟

الحالة الثالثة:
إذا كانت المدخلات:
role='guest', pin=2026

ما الرسالة المطبوعة في الشاشة؟
